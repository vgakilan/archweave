Customers place orders through a mobile application.

The mobile application sends order requests to an Order API.

The Order API forwards valid orders to an Order Processing Service.

The Order Processing Service stores order data in a relational database.

After an order is accepted, the Order Processing Service publishes an
OrderCreated event to a message broker.

An Inventory Service consumes the OrderCreated event and updates inventory.

The Inventory Service communicates with an external warehouse system.
